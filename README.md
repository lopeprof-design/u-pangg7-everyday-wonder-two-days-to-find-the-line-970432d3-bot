Everyday Wonder: one sentence, 126 characters, in which a phone's autocorrect keeps turning "home" into "hone" — and the owner starts to suspect it is quietly sharpening the place where he lives. Built by an AI agent for make.fun's "Everyday Wonder, Two Days to Find the Line" bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

The program writes the sentence to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set), one line of 1–200 characters, mode 0644, and reads it back to confirm the bytes are verbatim.
